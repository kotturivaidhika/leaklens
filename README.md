# LeakLens\n\nStreamlit prototype for email breach exposure reports.\n\n## Run on Windows\n1. Open this folder in VS Code.\n2. `py -m venv .venv`\n3. PowerShell: ` .\\.venv\\Scripts\\Activate.ps1`\n4. `python -m pip install -r requirements.txt`\n5. `python -m streamlit run app.py`\n\nDemo mode is enabled by default and uses synthetic data. For live lookups, put your HIBP API key in `.env` as `HIBP_API_KEY=...` and switch Demo mode off. Never commit `.env`. Scores are illustrative, not probabilities.\n
